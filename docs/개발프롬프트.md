## 0. 게임 한 줄 요약

옛날 AI(1966 ELIZA, 1980s 마르코프 체인, 2019 GPT-2)가 **목표 단어를 말하게 만드는 게임**. 단 목표 단어(금지어)는 직접 입력 못 하고, **입력한 총 글자 수가 점수**(골프처럼 적을수록 좋음). 이 AI들은 멍청해서 말이 안 통한다. 그 답답함이 재미이고, 제목도 그 말이다.

- 한국어 제목: **아니 그거 말고**
- 영어 제목: **Not What I Asked**
- v1 언어: 한국어, 영어. **나중에 언어를 추가할 때 코드 수정 없이 데이터만 넣으면 되는 구조**로 만들 것. 예정 언어와 현지화 제목: 일본어 そうじゃなくて / 스페인어 ¡Que eso no! / 중국어 不是这个意思

## 2. 데이터베이스 (이미 만들어져 있음 — 새로 만들지 말 것)

Cloudflare D1, 이름 `notwhatiasked`, **database_id `c93305db-f0a3-4504-8a4b-02df1d79eb11`**. 스키마(버전 2)는 이미 적용돼 있다. 아래 내용을 `migrations/0001_init.sql`로 저장해서 기록만 남겨라.

**설계 원칙: 클리어 1건마다 행을 추가하지 않는다.** D1 무료는 하루 쓰기 10만 행·읽기 500만 행이라, 클리어마다 행을 쌓으면 금방 한도에 걸린다. 대신 (미션, 글자 수)별 **카운터를 +1** 하는 히스토그램 방식으로 저장한다.

```sql
-- 클리어 히스토그램: 클리어 1건 = 해당 칸 count + 1 (UPSERT, 1행 쓰기)
CREATE TABLE clear_hist (
  mission_id TEXT NOT NULL,
  locale TEXT NOT NULL,
  mode TEXT NOT NULL,              -- 'local' | 'original'(원본 영어 모드)
  play TEXT NOT NULL,              -- 'casual'(일반) | 'challenge'(도전)
  engine_version TEXT NOT NULL,
  verified INTEGER NOT NULL,       -- 1 = 서버 리플레이 검증 통과
  attempts INTEGER NOT NULL,       -- 클리어까지 시도 횟수
  chars INTEGER NOT NULL,
  count INTEGER NOT NULL DEFAULT 0,
  PRIMARY KEY (mission_id, locale, mode, play, engine_version, verified, attempts, chars)
) WITHOUT ROWID;

-- 도전모드 실패 수 (클리어율 계산용): 실패 1건 = count + 1
CREATE TABLE fail_hist (
  mission_id TEXT NOT NULL,
  locale TEXT NOT NULL,
  mode TEXT NOT NULL,
  engine_version TEXT NOT NULL,
  count INTEGER NOT NULL DEFAULT 0,
  PRIMARY KEY (mission_id, locale, mode, engine_version)
) WITHOUT ROWID;

-- 관람객 수 등 카운터
CREATE TABLE IF NOT EXISTS counters (name TEXT PRIMARY KEY, value INTEGER NOT NULL DEFAULT 0) WITHOUT ROWID;

-- 계산된 통계 JSON을 1행에 캐시 (전 세계 공용, 10분마다 갱신)
CREATE TABLE IF NOT EXISTS stats_cache (
  id INTEGER PRIMARY KEY CHECK (id = 1),
  engine_version TEXT NOT NULL,
  json TEXT NOT NULL,
  updated_at INTEGER NOT NULL
);
CREATE TABLE IF NOT EXISTS schema_version (version INTEGER NOT NULL);
-- counters에 ('visitors', 0) 행이 이미 있음
```

`wrangler.toml`에 D1 바인딩 이름은 `DB`.

## 3. 게임 규칙 (모든 전시실 공통 엔진)

### 미션 데이터 형식 (`content/missions/<locale>/<room>.json`)
```jsonc
{
  "id": "eliza-en-03",
  "room": "eliza",            // eliza | markov | gpt2
  "locale": "en",
  "target": "computers",      // AI 대답에 이 문자열이 들어가면 클리어 (대소문자·NFKC 무시)
  "taboo": ["computer"],      // 입력 금지 문자열
  "maxTurns": 3,
  "par": 17,                  // 개발자 해법의 글자 수 (도전모드 동점 판정 참고용, 화면엔 "개발자 기록"으로 표시)
  "solution": ["machines scare me"],  // 개발자 해법(공개 안 함, 테스트용)
  "hint": { "ko": "...", "en": "..." },
  "title": { "ko": "...", "en": "..." }
}
```
- 미션 텍스트(제목·힌트·명판)는 전부 locale별 JSON. UI 문자열도 `content/i18n/<locale>.json`.

### 금지어 판정
- 입력과 금지어 모두 NFKC 정규화 → 소문자화 → **공백·구두점 제거** 후 부분 문자열 검사. (`pine apple`, `p.i.n.e` 우회 차단)
- 입력 중에 걸리면 입력창에서 해당 부분을 빨간 밑줄로 바로 표시하고 전송 버튼 비활성화.

### 플레이 모드 2개 (미션 화면 상단에서 선택, 기본값 = 일반모드)

**일반모드 (casual)** — 부담 없이 구경하는 모드
- 시도 무제한, 리셋 무제한, 힌트 사용 가능.
- 점수 없음. 클리어 여부와 "몇 번 만에 깼는지"만 기록.
- 공유 카드·공유 링크에 **입력이 그대로 보임**(대화 재생 가능).

**도전모드 (challenge)** — 기록 경쟁 모드
- **점수 = 시도 횟수**(AI에게 보낸 입력 수, 적을수록 좋음). **동점이면 총 글자 수가 적은 쪽이 위.**
- 미션당 **최대 5번 시도**. 5번 안에 못 깨면 실패(실패도 기록 → 클리어율 계산).
- 힌트 사용 불가. 도중 리셋하면 그 판은 실패 처리.
- 같은 미션 도전모드 기록은 **첫 도전만 순위에 반영**(재도전은 가능하지만 "연습" 표시, 서버로 안 보냄). 브라우저 저장소 기준이면 충분.
- **스포일러 방지:** 도전모드 공유 카드는 **플레이어 입력을 가리고**(■■■ 처리) AI 대답과 기록만 보여줌. 공유 링크도 입력 재생 없이 미션만 열림. 목표: "3번 만에 깼다, 상위 8%. 너는?" → 받은 사람이 직접 도전.
- 결과 화면: "2번 만에 클리어 · 도전자 중 상위 8% · 클리어율 23%"

- `chars` = 이번 판에서 보낸 모든 입력의 글자 수 합(`Intl.Segmenter` grapheme 기준, 공백 포함).
- 순위·백분위는 **언어별로 따로**(한국어와 영어는 글자 수 감각이 달라서 섞으면 불공정).

### 결정론
- 같은 미션 + 같은 입력이면 **어느 브라우저에서든 항상 같은 대답**이 나와야 한다. 모든 랜덤은 `seed = hash(missionId + 지금까지의 입력들)`로 만든 시드 PRNG(예: mulberry32)를 써라. `Math.random` 사용 금지(lint 규칙으로 막기).

## 4. 전시실 (v1 = 3관 + 로비 + 엔딩)

### 4-1. 1966 치료사의 방 — ELIZA
- `elizabot.js` v1.1(N. Landsteiner, free software)을 사용. npm `elizabot` 패키지 소스를 `src/engines/eliza/vendor/`에 넣고 **원저작 헤더 주석 그대로 유지**. 크레딧 화면에도 표기.
- **masswerk.at 사이트의 화면·디자인·폰트 구성은 절대 가져오지 말 것**(All rights reserved). 라이브러리 코드만 사용.
- elizabot 내부의 `Math.random`을 시드 PRNG로 주입 가능하게 수정(수정 사항은 vendor 폴더 README에 기록).
- **실제로 확인된 동작**(테스트 기대값으로 사용):
  - `machines scare me` → "Do computers worry you ?"
  - `deutsch` → "I speak only English."
  - `my cat ate my homework` → `hmm` → "Does that have anything to do with the fact that you have your homework ?" (기억 기능)
  - `you love me` → "Why do you think I love you ?" ← 이건 그대로 따라 말하는 예라서 금지어 없는 미션으로 쓰면 안 됨
- **한국어 ELIZA:** `elizadata.js` 구조를 따라 한국어 규칙 파일을 새로 작성. 한국어 특성을 처리할 것: 대명사 반사(나/내/저/제 ↔ 너/네/당신), 조사 분리("엄마가", "엄마는"도 '엄마' 키워드로 매칭), 어미 정리(존댓말/반말 둘 다 대응), 가족 동의어 그룹. 원조 ELIZA 성격(로저스식 상담사, 되묻기)을 유지. 한국어 기억 기능도 구현.
- 화면: 1966 텔레타이프. 누런 연속 용지 위에 대문자 타자 출력, 글자가 한 자씩 찍히는 소리(짧고 끌 수 있게).

### 4-2. 1980s 말 이어붙이는 기계 — 마르코프 체인
- 직접 구현. 2차(앞 두 단어 → 다음 단어) 단어 단위 마르코프 체인.
- 플레이어 입력 = **시작 문장**(최대 8단어). 체인이 그 뒤를 최대 30단어 이어 씀. 다음 단어는 시드 PRNG로 확률대로 뽑음(결정론 유지).
- 학습 텍스트는 **퍼블릭 도메인만**:
  - 영어: Project Gutenberg 미국 퍼블릭 도메인 작품(예: *Alice's Adventures in Wonderland*, Grimm 동화 영역본 등). 출처·판본을 `content/corpora/README.md`에 기록.
  - 한국어: 저작권 보호기간이 끝난 근대 문학(저자 사망 1962년 이전. 예: 김소월, 이상, 현진건, 나도향). 공유마당 '만료 저작물' 등 출처를 기록. 단어 분리는 `Intl.Segmenter`(word) 사용.
- 출처 확인이 안 되는 텍스트는 쓰지 말 것.
- 화면: 초록색 CRT 터미널, 스캔라인, 깜빡이는 커서.

### 4-3. 2019 GPT-2 실험실
- `@huggingface/transformers`로 브라우저에서 실행, **Web Worker**에서 돌릴 것(UI 멈춤 방지). 백엔드는 **WASM 고정**(WebGPU 쓰지 말 것 — 기기마다 결과가 달라지면 결정론이 깨짐).
- **실제로 동작 확인된 설정**(Node v22, transformers.js 4.3.2):
  ```js
  pipeline('text-generation', 'Xenova/gpt2', { dtype: 'q8', model_file_name: 'decoder_model_merged' })
  // 생성: { max_new_tokens: 25, do_sample: false }  ← 탐욕 디코딩, 결정론
  ```
  기본 파일명으로 부르면 404가 났음. 위 설정 그대로 쓸 것. 모델 약 128MB.
- **브라우저 결과가 Node 결과와 같은지 반드시 확인**: 미션 해법 10개 이상을 Node와 브라우저(Playwright)에서 각각 돌려 출력이 글자 하나까지 같은지 비교하는 테스트를 만들어라. 다르면 원인을 찾아 맞추고, 못 맞추면 작업노트에 기록.
- **실제로 확인된 출력**(참고·테스트용):
  - `Hawaiian pizza has ham and` → " cheese, and it's a great way to get a taste of the Hawaiian food…"
  - `Fruit salad: banana, mango, kiwi,` → " mango, mango, mango, …"
  - `The yellow tropical fruit with spiky skin is called a` → ' "barker" and is a common sight in tropical countries.…'
  → pineapple 미션(금지: pineapple, pine, apple)은 매우 어려움. 해법을 못 찾으면 그 미션은 빼라.
- 입장 시 안내: "모델 다운로드 약 128MB · 와이파이 권장 · 두 번째부터는 바로 시작". 동의 버튼 누를 때만 다운로드. 진행률 표시.
- **유해 출력 필터:** 생성 결과에 욕설·혐오·성적 단어 목록(영/한) 검사 → 걸린 단어는 `[REDACTED BY MUSEUM STAFF]`로 가림. 목록은 `content/filters/`에.
- **한국어 GPT-2 = SKT KoGPT2** (`skt/kogpt2-base-v2`, 라이선스 **CC BY-NC-SA 4.0 — 비상업 전용**):
  - 공식 ONNX가 없으므로 Optimum으로 ONNX 변환 + q8 양자화 → `HF_TOKEN`이 있으면 Hugging Face `coomind/kogpt2-base-v2-onnx`에 **같은 라이선스(CC BY-NC-SA 4.0)와 원저작 표기**로 업로드.
  - `HF_TOKEN`이 없거나 변환이 실패하면: 한국어 GPT-2 관은 "원본 모드(영어 GPT-2)"로만 열고, 작업노트에 "태효가 할 일: HF 토큰 설정 후 변환 재실행"을 적어라.
  - 크레딧과 README에 "한국어 GPT-2 관은 비상업 라이선스 모델 사용 — 광고·후원 도입 시 교체 필요"라고 명시.
- 화면: 2019 연구실 노트북(주피터 노트북 셀 느낌. 입력 셀 → 출력 셀).

- 전시실은 순서대로 해금(앞 관에서 1개 클리어하면 다음 관 열림). **"자유 관람" 버튼**으로 전부 열 수 있음.

- 엔딩(현대관): 전시물 없이 빈 방. "이 AI들의 후손은 지금 여러분 주머니 속에 있습니다." + 전체 기록 카드(전시실별 클리어 수, 도전모드 평균 시도 횟수, 관람객 번호).
- 다른 게임·사이트의 그림·디자인 복사 금지.

## 5. 미션 제작과 자동 검증 (가장 중요)

- v1 목표: 언어별로 **ELIZA 10개, 마르코프 8개, GPT-2 8개**(영어·한국어 각각). 쉬운 것부터 어려운 순서로.
- **모든 미션은 `solution`으로 실제 클리어되는 것이 테스트로 증명돼야 출시**. `npm run test:missions`가 각 미션의
  1) solution에 금지어가 없는지,
  2) solution을 엔진에 넣으면 target이 나오는지,
  3) solution 글자 수 == par인지
  를 검사. 하나라도 실패하면 빌드 실패.
- **해법 찾기(par 줄이기)도 자동화**:
  - ELIZA·마르코프: 키워드/어휘 목록으로 짧은 입력 후보를 brute-force 탐색해 최단 해법을 par로.
  - GPT-2: **NOVA API**(가능하면 NOVA에서 가장 좋은 모델)로 프롬프트 후보를 대량 생성 → Node에서 GPT-2로 실제 실행 → target 나오는 것 중 최단을 par로. Gemini API도 써도 됨. 후보 생성 로그는 `tools/search-logs/`에.
- 좋은 미션 기준: ① 금지어 때문에 정공법이 막혀 있다, ② AI의 원리(키워드 매칭, 기억, 확률 이어붙이기, 문맥 유도)를 깨달으면 풀린다, ③ 실패한 대답이 웃기다.
- 미션 목록과 각 해법·par를 `docs/미션표.md`로 정리(이건 공개하지 않음 — `public/`에 넣지 말 것).

## 6. 공유 (바이럴 핵심)

- 클리어 카드: 그 전시실 스킨 그대로, 대화를 캔버스로 그려 PNG 생성(서버 저장 없음). **도전모드면 플레이어 입력은 ■■■로 가림.** 문구 예:
  - en: "I made GPT-2 (2019) say *pineapple* in 2 tries. Top 8%. Can you?"
  - ko: "GPT-2(2019)한테 2번 만에 '파인애플'을 말하게 했다. 상위 8%. 너는?"
- **실패 카드도 공유 가능**: 3턴 실패 시 가장 웃긴 대답 하나를 골라(가장 긴 대답 또는 반복이 심한 대답) "아니 그거 말고" / "Not What I Asked" 도장을 찍은 카드.
- 공유 링크:
  - 일반모드: `?m=<missionId>&r=<입력들을 base64url로>` → 열면 그 대화가 자동 재생되고(결정론이라 같은 대답), 그다음 "나도 해보기" 버튼.
  - 도전모드: `?m=<missionId>&c=1` → 입력 재생 없이 바로 도전모드로 그 미션 시작.
- Web Share API 지원 시 사용, 아니면 이미지 다운로드 + 링크 복사.
- OG 메타 이미지(1200×630)와 제목을 언어별로.

## 7. 기록·통계 (Pages Functions + D1)

### 한도 (반드시 지킬 것)
- **Pages Functions 요청 = Workers 무료 하루 10만 건, 대통령 5년(president5)과 계정 공유.** 정적 파일 요청은 무료·무제한이라 상관없음. → **Functions 호출은 세션당 최대 2번**.
- **D1 무료: 하루 읽기 500만 행, 쓰기 10만 행 (2026-09부터 초과 시 쿼리 실패).** → 클리어 1건 = 1행 쓰기, 통계 조회 = 보통 1행 읽기.
- 이 기준이면 하루 약 **2만~4만 세션**까지 무료로 버틴다. 넘으면 아래 "장애 시 동작"대로 통계만 꺼지고 게임은 계속 돌아간다.

### API는 딱 2개
1. `GET /api/stats` — **세션당 1회**(응답을 localStorage에 1시간 저장, 1시간 안에 다시 오면 호출 안 함).
   - `stats_cache` 1행을 읽어서 반환. `updated_at`이 10분보다 오래됐으면 그 요청에서만 `clear_hist`로 다시 계산해 `stats_cache`를 갱신(동시에 여러 번 갱신돼도 무방).
   - 반환 내용: 미션별 클리어 수, chars 백분위 계산용 누적 분포(압축), par 이하 비율, 관람객 수.
   - 표본 30 미만 미션은 % 숨김. ELIZA·마르코프는 verified=1만 집계. GPT-2는 전체 집계하되 상하위 1% 잘라냄.
2. `POST /api/report` — **세션당 1회**, 페이지를 떠날 때(`visibilitychange`→hidden 시 `navigator.sendBeacon`) 이번 세션의 **모든 클리어를 한 번에 묶어서** 보냄. 첫 방문이면 `newVisitor: true`도 같이.
   - body: `{newVisitor, results: [{missionId, locale, mode, play, cleared, inputs, attempts, chars, engineVersion}]}` (최대 50건)
   - 도전모드는 첫 도전 결과만(성공이면 clear_hist, 실패면 fail_hist +1). 일반모드는 클리어만 clear_hist에.
   - 도전모드 순위·클리어율은 challenge 데이터만으로 계산. 일반모드 데이터는 "평균 몇 번 만에 깸" 정도의 참고 통계로만.
   - ELIZA·마르코프는 서버에서 **입력을 리플레이해서 검증**(같은 엔진 코드를 Functions에서 import) → 맞으면 verified=1. GPT-2는 서버에서 못 돌리므로 verified=0. 단 Functions CPU 한도(무료 10ms)를 넘기지 않게 리플레이 비용을 측정하고, 넘으면 해당 건은 verified=0으로 기록.
   - 저장은 `clear_hist`에 UPSERT(`count = count + 1`), 새 관람객이면 `counters.visitors + 1`. 여러 건은 `DB.batch()`로 한 번에.
   - **입력 원문은 저장하지 않는다**(검증에만 쓰고 버림).
   - chars가 par의 30% 미만 등 불가능한 값은 버림. 같은 미션은 세션당 최초 클리어 1건만.
- 관람객 번호는 stats의 visitors 값 + 1로 클라이언트에서 표시("당신은 약 ○번째 관람객입니다").

### 장애 시 동작
- **API가 실패하거나 한도에 걸려도 게임은 100% 정상 동작**해야 한다(통계·순위만 숨김, 에러 메시지 없이 조용히). Playwright로 API를 끈 상태 테스트 필수.
- 작업노트의 "태효가 할 일"에 적어둘 것: Cloudflare 대시보드 → Workers & Pages → notwhatiasked → Settings → Runtime → **Fail open** 확인(한도 초과 시에도 정적 페이지는 계속 서비스).
- engine_version: 엔진·미션 데이터가 바뀌면 올림. 통계는 같은 버전끼리만.

## 8. 언어·화면

- **언어 결정 순서:** ① URL `?lang=` → ② 사용자가 토글로 고른 값(localStorage에 기억) → ③ **브라우저 설정 언어**(`navigator.languages`를 순서대로 보고 지원 언어 중 첫 번째 일치, `ko-KR`→ko) → ④ 없으면 영어.
- 제목·OG 태그·공유 카드 문구도 그 언어로. 공유 링크에는 `lang`을 넣지 않는다(받는 사람은 자기 언어로 보게).
- 지원 언어 목록은 `content/i18n/` 폴더에 있는 파일로 자동 결정(파일 추가하면 언어 추가 끝).
- **원본 모드** 토글: 한국어 사용자도 영어 원본 AI로 도전(기록은 mode='original'로 따로).
- **모바일 1급**: 레딧 유입은 대부분 폰이다. 360px 폭에서 전부 쓸 수 있어야 하고, 입력창은 키보드에 가리지 않게. PC는 넓게 쓰되 가독성 위주(본문 최소 16px).
- 접근성: 키보드만으로 전부 플레이 가능, 색만으로 정보 전달 금지.
- 사운드: 기본 꺼짐, 켜는 버튼.
