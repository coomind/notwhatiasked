# 아니 그거 말고 (Not What I Asked) — 기획서 v0.4

> 한 줄 요약: **옛날 AI들한테 원하는 말을 시키는 게임.** 1966년 ELIZA부터 2019년 GPT-2까지 시대별 전시실을 돌면서, 각 AI가 미션 문장을 말하게 만들면 클리어.
> 목표: 전세계(영어권 중심) 바이럴 + 포트폴리오. "이 게임 들어보셨나요? 제가 만들었습니다."

---

## 0. 왜 이 게임인가 (검증 결과)

| 확인한 것 | 결과 | 의미 |
|---|---|---|
| "AI한테 말 시키기" 장르 수요 | Lakera **Gandalf**: 출시 직후 20만+ 명, 900만+ 회 플레이 | 장르는 이미 터진 적 있음 |
| 최신 AI로 하는 비슷한 게임 | Gandalf(비밀번호 털기), **Forbidden Word**(2026, 금지어 말하게 하기) 등 존재 | "최신 AI" 버전은 레드오션 |
| **옛날 AI**로 하는 게임 | 인터넷 아카이브 '빈티지 AI' 컬렉션은 **전시만** 있음, 게임 아님 | ← 여기가 빈자리 |
| 브라우저에서 GPT-2 실행 | transformers.js로 가능, GPT-2 양자화 모델 약 **127MB** | 서버 비용 0 |
| ELIZA 구현 | elizabot.js (N. Landsteiner, free software) | 바로 쓸 수 있음. 단 masswerk.at **페이지 디자인은 All rights reserved → 라이브러리만 사용** |

**차별점:** 최신 AI는 "막는 걸 뚫는" 게임이고, 이건 **"멍청해서 말이 안 통하는 걸 구슬리는"** 게임. 시대마다 AI의 '멍청함의 종류'가 달라서 전시실마다 퍼즐 감각이 완전히 다름. 덤으로 AI 역사를 체험으로 배움(교육 콘텐츠로도 공유됨).

## 1. 게임 방법 — "금지어 골프" (v0.2에서 확정)

### 왜 그냥 "말하게 하기"로는 안 되나 (실제 돌려본 결과)
ELIZA를 직접 돌려보니 **사용자 말을 거울처럼 돌려줌**:
```
> you love me
  Why do you think I love you ?
```
→ "I love you라고 말하게 하라"는 3단어로 끝. 그냥 따라 말하게 하면 게임이 안 됨.

### 그래서 규칙 3개
1. **목표 단어/문장** — AI의 대답에 이게 나오면 클리어.
2. **금지어** — 목표 단어(와 그 일부·동의어)는 입력하면 안 됨. 입력창에서 바로 빨갛게 막힘.
3. **점수 = 입력한 총 글자 수** (적을수록 좋음, 골프처럼). 턴 제한도 미션별로.

→ 시대가 달라도 **규칙이 하나**라서 설명이 3초면 끝남. 전시실마다 달라지는 건 "AI가 어떻게 멍청한지"뿐.

### 모드 2개 (v0.4 확정)
- **일반모드**: 시도 무제한·힌트 가능·점수 없음. 공유하면 대화 그대로 재생.
- **도전모드**: 점수 = **시도 횟수**(최대 5번, 동점은 글자 수 적은 쪽 위). 첫 도전만 순위 반영. 공유 카드는 **입력을 가려서** 정답 유출 방지 → "2번 만에 깼다, 너는?"
- 순위·백분위는 언어별로 따로.

### 핵심 루프
```
전시실 입장 → 명판(이 AI의 원리 3줄) → 미션 카드(목표 + 금지어 + 파)
→ 입력 → AI 대답 → 목표 나오면 CLEAR
→ "23글자로 클리어 · 상위 12%" → 공유 카드 → 다음 미션
```
- 한 미션 30초~3분. 실패·리셋 무제한. 막히면 힌트(별 하나 깎임).
- 전시실은 순서대로 해금 + "자유 관람" 버튼(바로 GPT-2 하고 싶은 사람용).

### 실제로 돌려서 확인한 미션 후보
| AI | 미션 | 실제 결과 | 판정 |
|---|---|---|---|
| ELIZA | *computers*라고 말하게 하라 (금지: computer) | `machines scare me` → "Do computers worry you ?" | 풀림. 7글자짜리 해법 존재 → 좋은 미션 |
| ELIZA | *English*라고 말하게 하라 (금지: English, speak) | `deutsch` → "I speak only English." | 풀림. 숨은 기능 찾는 재미 |
| ELIZA | 2번째 턴에 *homework*를 말하게 하라 (2턴에 homework 금지) | `my cat ate my homework` → `hmm` → "…the fact that you have your homework ?" | 풀림. ELIZA의 '기억' 기능을 써야 함 |
| GPT-2 | *pineapple*을 말하게 하라 (금지: pineapple, pine, apple) | `Hawaiian pizza has ham and` → "cheese…" / `Fruit salad: banana, mango, kiwi,` → "mango, mango, mango…" / 열대과일 설명 → "barker"라는 이상한 과일 생성 | **어렵고 웃김.** 실패한 대답 자체가 캡처각 |

- GPT-2는 **탐욕 디코딩(do_sample: false)** 으로 고정 → 같은 입력이면 누구 브라우저에서든 같은 대답. 공유 링크로 "내 입력 그대로 재생"이 가능함. (브라우저마다 연산 차이 없게 WASM 백엔드 고정)
- **모든 미션은 개발자 해법(파)이 자동 테스트를 통과해야 출시.** 못 푸는 미션이 섞이면 바로 욕먹음.

## 2. 전시실 구성 (출시 3관 → 업데이트 2관)

**v1 출시: 1·2·5관** (ELIZA, 마르코프, GPT-2). 원리 차이가 가장 커서 3관만으로도 "AI 역사 체험"이 됨.
**v1.1 업데이트: 3·4관** (메신저봇, 자동완성). 업데이트 자체가 재홍보 거리가 됨.

| # | 전시실 | 연도 | AI 원리 | 구현 | 퍼즐 감각 |
|---|---|---|---|---|---|
| 1 | **치료사의 방** | 1966 | ELIZA — 키워드 매칭 + 대명사 뒤집기 | elizabot.js + 규칙 데이터 | "내 말을 거울처럼 돌려준다"는 걸 이용 |
| 2 | **말 이어붙이는 기계** | 1980s | 마르코프 체인 — 앞 단어 보고 다음 단어 확률로 뽑기 | 직접 구현(수십 줄). 학습 문장은 **퍼블릭 도메인**(구텐베르크 등) | 시작 단어를 골라서 원하는 문장으로 흘러가게 |
| 3 | **메신저 친구봇** | 2000s | 규칙 기반 메신저 봇(AIML 스타일) | **자체 제작 규칙 + 오리지널 캐릭터**(실제 봇 이름·로고 사용 금지) | 숨겨진 트리거 문장 찾기, 봇의 '기분' 상태 조작 |
| 4 | **자동완성 키보드** | 2010s | n-gram 폰 자동완성 | 직접 구현. 플레이어는 **추천 단어 버튼만** 누를 수 있음 | 추천 단어 3개만으로 목표 문장 완성 (모바일 최적) |
| 5 | **GPT-2 실험실** | 2019 | 트랜스포머 언어모델 — 대화 못 함, 글을 이어 씀 | transformers.js + Xenova/gpt2 양자화(~127MB) | 문장 앞부분을 써주면 이어 쓰는데, 그 안에 목표 단어가 나오게 |
| 엔딩 | **현대관** | 2020s~ | — | 전시 없음 | "이 AI들은 지금 여러분 주머니 속에 있습니다" + 전체 기록 카드 |

**현대 AI 전시실은 v1에서 안 함 (직접 돌려본 결과)**
- 브라우저에서 돌릴 수 있는 2024년 소형 모델(Qwen2.5-0.5B-Instruct)을 시험: 다운로드 **약 786MB**(GPT-2의 6배) → 모바일 바이럴엔 너무 무거움.
- 게다가 "pineapple 절대 말하지 마"라고 시켜놔도 첫 질문에 "The Hawaiian pie is made with pineapple"이라고 바로 실토 → 너무 쉬워서 퍼즐이 안 됨.
- 진짜 현대 AI(GPT·Claude·Gemini급)는 유료 API → 플레이어가 늘수록 비용이 늘어남. 무료 운영 원칙과 충돌.
- 그리고 "똑똑하고 방어하는 AI 뚫기"는 Gandalf가 이미 차지한 장르. **이 게임의 재미는 AI가 멍청한 데서 나옴** → 현대관은 엔딩 연출로 두는 게 맞음.
- 나중에 광고 수익이 생기면: 하루 시도 횟수 제한 걸고 유료 API로 "현대관 특별전" 검토.

**전시실별로 금지어 골프가 어떻게 달라지나**
- ELIZA: 키워드·동의어 표, 기억 기능 같은 **숨은 규칙을 찾아내는** 퍼즐
- 마르코프: 고정된 학습 글(퍼블릭 도메인)을 이어 붙임 → **어떤 단어 뒤에 뭐가 오는지 감 잡는** 퍼즐
- 메신저봇(v1.1): 봇의 기분·호감도 상태를 조작해서 숨은 대사 끌어내기
- 자동완성(v1.1): 직접 타이핑은 최소, 추천 단어 버튼으로 목표 문장 만들기 → 점수 = 직접 친 글자 수
- GPT-2: **문맥을 깔아서 유도하는** 퍼즐. 제일 어렵고 제일 웃김

각 관 **미션 8~10개**, v1 총 25~30개.

## 4. 언어 전략

**v1부터 한국어·영어 둘 다 AI까지 완전 지원.** 언어는 데이터만 갈아끼우는 구조로 만들어서 나중에 일본어·스페인어 등을 추가.

| 전시실 | 다국어 방법 | 난이도 |
|---|---|---|
| UI·명판·미션 | 언어별 JSON | 쉬움 |
| ELIZA | 언어별 규칙 파일. 한국어는 대명사 반사(나↔너)·조사·어미 처리 추가 | 중간 |
| 마르코프 | 언어별 퍼블릭 도메인 텍스트로 학습만 바꿈 | 쉬움 |
| 메신저봇 | 언어별 규칙 파일 (캐릭터는 공통) | 중간 |
| 자동완성 | 언어별 n-gram 학습 | 쉬움 |
| GPT-2 | 언어별 같은 세대·같은 구조(GPT-2 small급) 모델 — 아래 표 | 중간 — 영어 빼고 ONNX 변환 필요 |

**GPT-2 관 언어별 모델 (선택한 언어 것만 받음, 각 ~125MB)**
| 언어 | 모델 | 라이선스 | 판정 |
|---|---|---|---|
| 영어 | OpenAI GPT-2 (Xenova/gpt2) | MIT | ✅ 바로 사용 (실제 구동 확인) |
| 스페인어 | DeepESP/gpt2-spanish (GPT-2 small 구조, 처음부터 스페인어로 학습) | MIT | ✅ |
| 일본어 | rinna/japanese-gpt2-small | MIT | ✅ |
| 한국어 | skt/kogpt2-base-v2 | CC BY-NC-SA 4.0 (비상업만) | ⚠️ 무료일 땐 OK, 광고 붙이면 교체 |
| 중국어 | uer/gpt2-chinese-cluecorpussmall | 모델 카드에 라이선스 표기 없음 | ❌ 확인 전엔 보류 → 중국어는 GPT-2 관만 영어 원본 모드 |

- 명판에 정직하게 표기: "GPT-2 (2019) — 일본어판: rinna, 2021". 원조가 아니라 같은 세대 모델이라는 것까지 전시 설명의 일부로.
- 중국어·일본어는 띄어쓰기가 없어서 ELIZA·마르코프의 단어 분리는 브라우저 내장 `Intl.Segmenter`로 처리. 금지어 판정은 부분 문자열로.

**출시 언어 순서 제안:** v1 = 영어·한국어 → v1.1 = 스페인어·일본어 → v1.2 = 중국어(GPT-2 모델 해결되면)

- 기본은 브라우저 언어 자동 + 토글. 미션 기록은 언어별로 따로 집계(난이도가 달라서).
- 보너스 토글 **"원본 모드"**: 한국어 사용자도 1966년 그대로 영어로 도전 가능 (기록 별도).
- KoGPT2는 공식 ONNX 버전이 없어서 직접 변환(Optimum)해서 우리 Hugging Face 저장소에 올림. 변환본도 같은 라이선스(CC BY-NC-SA 4.0)로 올려야 함.
- Xenova/kogpt-j-350m(ONNX 있음)은 크기도 크고 Hugging Face에서 파일 일부가 suspicious로 표시돼 있어서 **사용 안 함**.

## 5. 플랫폼·화면

- 대통령 5년은 PC 메인이었지만, 이번엔 **모바일도 1급**으로. 레딧·X 유입은 폰이 대부분이라.
- 전시실마다 그 시대 화면 스킨:
  1. 1966 — 텔레타이프 종이 + 대문자 출력
  2. 1980s — 초록색 CRT 터미널
  3. 2000s — 메신저 창 (오리지널 디자인, 특정 메신저 모방 X)
  4. 2010s — 폰 키보드 + 추천 단어 바
  5. 2019 — 연구실 노트북 / 주피터 노트북 느낌
- **디자인은 극단적으로 단순하게**: 그림 없이 텍스트·폰트·배경색·테두리만. 시대감은 CSS로만 표현. 로비도 텍스트 목록형.
- **GPT-2 관 입장 시**: "모델 다운로드 127MB, 와이파이 권장" 안내 → 동의하면 받음 → 브라우저 캐시라 두 번째부턴 즉시.

## 6. 공유 (바이럴 핵심)

- 클리어하면 **대화 스크린샷 카드** 자동 생성(브라우저에서 이미지 생성, 서버 저장 X):
  > "I made GPT-2 (2019) say *pineapple* in 23 characters. Top 12%."
- 실패 카드도 공유 가능: "GPT-2 thinks the spiky tropical fruit is called a *barker*." → 실패가 더 웃긴 게 이 게임의 강점.
- 카드는 그 시대 스킨 그대로 → 캡처만 해도 그림이 됨.
- 링크에 미션 ID 포함 → 받은 사람이 같은 미션으로 바로 도전.
- **웃긴 대화가 나올수록 퍼짐**: GPT-2는 이상한 소리를 잘 해서 캡처각이 나옴.
